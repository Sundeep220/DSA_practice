# DSA Handbook Bundle

Files in this bundle:
- `DSA_Interview_Pattern_Handbook.md` — core explanations, math, decision tree, Java 17 templates, roadmap.
- `DSA_Interview_Pattern_Handbook.pdf` — formatted PDF with page numbers and clickable links for Markdown links rendered in the PDF.
- `DSA_Pattern_Recognition_Cheat_Sheet.md` — compact revision sheet.
- `DSA_LeetCode_Practice_Catalog.md` — categorized problem list with difficulty, clue, priority, and links.
- `DSA_Pattern_Identification_Workbook.md` — shuffled exercises and separate answer key.

Link verification note: official LeetCode canonical URLs were used, and web search was used to cross-check pattern taxonomy and selected references. The catalog has not been automatically checked URL-by-URL, so individual link availability is not guaranteed. The PDF prioritizes readable text and clickable inline Markdown links; Markdown tables are represented as compact text rows rather than fully typeset table grids.
